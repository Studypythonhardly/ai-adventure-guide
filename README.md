# 🤖 AI 奇妙漫游指南 · AI Adventure Guide (2026 互动版)

一个面向普通计算机小白的**从 0 开始互动式 AI 入门教程**，全程采用 **ELI5（Explain Like I'm 5）大白话规范**，通过游戏化闯关、实时交互实验、3D WebGL 渲染与零代码造物沙盒，帮助读者全面理解 AI 原理、掌握 2026 前沿 AI 生态并亲手用 AI 做出作品。

## ✨ 核心功能亮点

- **🎮 游戏化学习体验**：6 大互动关卡 + 经验值（XP）升级体系 + 6 枚专属成就徽章 + 本地进度持久保存。
- **🧠 第 01 关 · AI 到底是个啥？**：
  - 词语接龙透视镜 + 脑洞滑块（Temperature 实时概率分布可视化）
  - 乐高切词机（Token 切分与 Context Window 上下文窗口实验）
- **🏆 第 02 关 · AI 已经牛到什么地步了？**：
  - 2026 年 11 月重磅案例：AI（Claude）+ 形式化验证（Lean）协助攻破 167 年“黎曼猜想”互动时间轴
  - 著名的“鹈鹕骑单车”进化史（2023 抽象派 → 2025 简笔画 → **2026 100% 纯代码 Three.js + GLSL 落日海岸 3D 实时渲染**，支持 360° 拖拽、切换机位与加速冲刺）
  - 4 题 AI 认知真假大挑战
- **🃏 第 03 关 · 2026 前沿 AI 英雄图鉴**：
  - 收录 Claude、GPT、Gemini、DeepSeek、通义千问 Qwen、豆包、Kimi、可灵/即梦/海螺 AI、Cursor/Trae/Antigravity 等 9 张收藏级卡牌 + “帮我选 AI！”场景匹配器
- **✨ 第 04 关 · AI 咒语学院 & AI Skill 技能包**：
  - R-T-C-F 万能咒语炼金工坊（开关 4 块积木实时对比 AI 输出蜕变）
  - 2026 进阶 **AI Skill 技能卡带** 互动体验 + `Prompt vs Skill vs MCP` 黄金对比
- **🛠️ 第 05 关 · 动手造物工坊（Vibe Coding 体验）**：
  - 零代码在线定制并试玩 3 个真实可用的小工具（今天吃什么大转盘、萌系番茄钟、赛博电子贺卡），支持**一键下载独立可运行的 `.html` 网页文件**与复制同款 Prompt
- **🎓 第 06 关 · AI 黑话翻译局 & 毕业典礼**：
  - 19 个高频 AI 术语词典，支持 **ELI5 三档听众切换**（5岁小朋友版 / 零基础小白版 / 职场实用版）
  - AI 防坑 4 条保命法则 + 终极毕业挑战 + 可自定义署名的 2026 荣誉毕业证书
- **🧰 常驻工具箱 · AI 实战案例库（24 个高频场景）**：
  - 覆盖职场办公、团队提效、日常生活、学习成长、创意副业、省钱避坑 6 大维度，支持搜索、本地收藏与一键复制现成咒语。

## 🚀 本地运行与构建

```bash
# 安装依赖
npm install

# 启动本地开发服务器 (默认 http://localhost:5173)
npm run dev

# 构建生产静态包 (输出至 dist/)
npm run build
```

## 🛠️ 技术栈

- React 19 + Vite 8 + Tailwind CSS 4
- Three.js（100% 纯代码 WebGL + 自定义 GLSL 着色器）
- Lucide React + Canvas Confetti
