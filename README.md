# 🤖 AI 奇妙漫游指南 · AI Adventure Guide

> 🌐 **在线游玩**：https://studypythonhardly.github.io/ai-adventure-guide/

一个面向普通计算机小白的**从 0 开始互动式 AI 入门教程**。全程采用 **ELI5（Explain Like I'm 5）大白话三段式**（一句话本质 + 生活比喻 + 跟你有什么关系），通过互动实验、任务式闯关、3D/2D 代码可视化与零代码网页工坊，既带你体验现代 AI 的高光能力，也帮你看清 AI 幻觉、时效与安全边界。

  - 乐高切词机（示意分词直觉 + 真实 BPE 分词说明 + 上下文窗口概念）
- **🏆 第 02 关 · AI 已经牛到什么地步了？**
  - 2026 年 11 月数学 × AI 案例：Levent Alpöge 与 Claude 借助 **Lean** 发布黎曼猜想形式化证明库的时间轴、代码量比例对比与**公开核查来源链接**

  - 冷静视角：**AI 目前仍然不擅长/不能盲信的 4 件事** + 4 题认知真假挑战
- **🃏 第 03 关 · 主流 AI 英雄图鉴**
  - 9 类代表性 AI 模型与工具卡牌 + “帮我选 AI”场景匹配器 + 不过时的 3 条选型铁律
- **✨ 第 04 关 · AI 咒语学院 & AI Skill 技能包**
  - R-T-C-F 四要素炼金工坊（开关积木实时对比输出变化）

## 🚀 本地开发与校验

```bash
# 安装依赖
npm install

# 启动本地开发服务器 (默认 http://localhost:5173)
npm run dev

# 运行代码规范检查 + 单元测试 + 生产构建（推荐提交前执行）
npm run check

# 也可单独运行：
npm run lint    # ESLint 静态检查
npm test        # Vitest 单元测试
npm run build   # Vite 生产分包构建 (输出至 dist/)
```

## 🛠️ 技术栈与无障碍支持

- **前端框架**：React 19 + Vite 8 + Tailwind CSS 4（关卡与 Three.js 引擎均按需异步拆包加载）
- **3D 与动效**：Three.js + 自定义 GLSL 着色器 + SVG 2D 降级方案 + Canvas Confetti（全程尊重系统 `prefers-reduced-motion` 减少动态效果设置）
- **质量保障**：ESLint 9 + Vitest + GitHub Actions 自动检查与 Pages 部署
